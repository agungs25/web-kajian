Pengaturan API Key

Untuk melakukan panggilan langsung ke API YouTube, Anda membutuhkan YouTube Data API v3 Key. Kunci ini disimpan secara lokal di browser Anda.

Bagaimana mendapatkan API Key?
Masuk ke Google Cloud Console, buat project baru, aktifkan "YouTube Data API v3", lalu buat Credentials API Key baru.
